# Склейка для macOS

Видеоредактор «Склейка» с русским интерфейсом и ИИ-ассистентом. Здесь только готовые сборки.

## Установка (один раз)

1. Скачайте **[Skleyka-mac.dmg](https://github.com/kimurazver67/reacut-releases/releases/latest/download/Skleyka-mac.dmg)** (Mac на Apple M1–M4). Файлы `blob-*.gz` в релизе — для автообновления, их скачивать не нужно.
2. Откройте DMG и перетащите Склейку в «Программы».
3. Программа не подписана Apple, поэтому macOS её заблокирует. Откройте Терминал и выполните (внутри системы файл называется ReaCut.app — так и надо):
   ```
   xattr -cr /Applications/ReaCut.app
   ```
4. Запустите Склейку.

## Обновления

Настройки → «Проверить обновления» → «Обновить и перезапустить». Программа сама скачает новую версию, сверит контрольную сумму, заменит себя и перезапустится.

## Лицензии

Склейка основана на [rea-capcut](https://github.com/Xiangyu-CAS/rea-capcut) (MIT). Встроенные FFmpeg и x264 распространяются по GPL-2.0-or-later, их исходники лежат в каждом релизе (`media-tool-sources.tar.gz`).
